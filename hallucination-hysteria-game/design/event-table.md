# Revised interaction events
| Action | Response | Player understanding |
|---|---|---|
| Start | First song loads, then short count-in | Enter the walk without a tutorial |
| Press matching arrow within 70ms | Perfect, +3 clarity, combo | Timing steadies the world |
| Press within 150ms | Good, +2 clarity | A forgiving timing window |
| Press too early / empty lane | No note consumed | Retry at the target |
| Miss a note | −6 clarity, combo resets | Keep the visible rhythm |
| Hold through tail | +2 clarity | Sustain long notes |
| Continue story | Next dialogue page / chapter | Why the location changes |
| Skip to song | Next chapter | Replay without reading again |
| Pause / leave window | Audio clock suspends | Progress does not run while away |
| End room above 50 | Clear ending | Walker reaches a moment of stability |
| End room at ≤50 | Lost ending | The familiar route repeats |
