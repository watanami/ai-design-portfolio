# Current state flow
Ready → Loading → Street → waiting transition → Loading → Stranger → waiting transition → Loading → Room → Clear or Lost → Ready.
No tutorial, no ghost notes and no gameplay dialogue. Each transition is a single short message.
Failure stops audio and waits indefinitely for manual Restart. Restart retains the stage and resets clarity to 50.
Pause suspends the audio clock; tab visibility never resumes automatically.
Lost fades to the street after five seconds but does not start playing; Start Again returns to title.
Clear's Play Again returns to title. Music credits remain below the game.
