# Reset rules
Start, next stage and Restart reset notes, judgments and clarity to 50; retain the chosen name and comfort settings.
Failure waits for manual Restart; no countdown or automatic retry.
Pause clears held inputs, suspends sound, and grants 300ms re-grip grace on Resume.
Transitions stop old music and load quiet next-stage ambience. Start next stage stops the ambience and reuses its decoded recording.
Ending replay returns to Ready, releases sound and resets name to Walker.
